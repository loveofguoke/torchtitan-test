Active collection overhead采集窗口相对普通 step 的膨胀过大时不要把该 run 当性能基线，应缩短窗口或换浅层 preset。
Computing / Communication / Overlapped / Free官方 StepTrace 的计算、通信、重叠和空闲时间优先关注 communication_not_overlapped 和跨 rank 最大值，而非通信总时长。
Transit / Wait / Synchronization真实传输、等对端和同步时间传输高倾向链路/载荷问题；等待高倾向上游计算或 rank readiness 偏斜。
